# AI-default looks

Read before showing the owner a direction, and when reviewing a screen. Generated interfaces cluster around these looks. Each is legitimate when a project chooses it on purpose; it is a tell when it arrives by default. When the owner or design.md asks for one, follow them.

## Palettes and surfaces

- Warm cream ground (near `#F4F1EA`), a high-contrast serif display face, a terracotta accent (near `#D97757`).
- Near-black ground (`#0B0B0B`, `#111`) with one acid-green or vermilion accent.
- A framework's stock palette used as shipped: untinted greys plus one blue or violet accent, colors picked by scale step (`gray-500`, `blue-600`).
- Purple-to-blue gradients, gradient text, glows, blobs, grid or dot backgrounds, glass panels.

## Layout

- The SaaS card kit: content chopped into identical rounded cards, cards inside cards, and one radius and one soft grey shadow (`rgba(0,0,0,.1)`) on every container regardless of hierarchy. Shadows tiered by elevation are a system, not this tell.
- A centered hero with a big number, a small label, supporting stats and a gradient accent, followed by a three-up grid of feature cards, each with an icon in a colored tile.
- The broadsheet: hairline rules, zero radius, dense newspaper columns.
- Every section the same silhouette whatever its content; borders added to repair weak hierarchy.

## Type and labels

- Inter, Geist or Roboto everywhere; Instrument Serif or Space Grotesk as the "editorial" accent.
- A tracked all-caps eyebrow above every heading.
- One word of a headline set apart in color or italic.
- `01 / 02 / 03` markers on content that is not a sequence.
- Middle-dot meta strings (`5 min · Design · 2026`) and `WORD — fragment` labels.
- `→` appended to link and button text.
- Small muted grey body text.

## Components

- Pills and badges for ordinary metadata.
- A filled pill as the selected state of every nav and tab bar.
- Icons as decoration, in colored tiles; a sparkle icon for anything AI.

## Motion

- Fade-and-slide-up on every section as it scrolls in.
- A lift and shadow on every card hover.
- Bouncing dots, confetti, mascots, animated gradients.

## The check

For each direction, write one line on the directions page: the nearest look above, and what in the direction moves it away. Then imagine the same prompt for a similar product; any distinguishing visual choice you would arrive at again is a default, not a choice, and gets revised before the owner sees it. Familiar interaction patterns, such as form layout and navigation, stay conventional. A sterile, everything-removed page is not the fix: the fix is a choice that comes from the subject.
